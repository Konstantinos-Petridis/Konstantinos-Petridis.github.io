01 — SQL case study

Sailor Analysis

Designing a relational database for sailor and charter data, then extracting business insights through SQL queries.

  • SQL Server
  • SSMS
  • Joins
  • Subqueries
  • Aggregations

The problem

This project analyses sailor and charter data using SQL. The objective was to design a relational database and extract business insights through SQL queries.

Process

  1. 01
    Schema designIdentified entities and relationships, and chose primary and foreign keys for data integrity and efficient querying.
  2. 02
    Tables & keysCreated the database and all tables in SQL Server Management Studio, enforcing relationships with constraints.
  3. 03
    Data loadingInserted the datasets with SQL scripts, paying attention to data types, nulls and formatting.
  4. 04
    Quality checksVerified record counts, detected missing values and confirmed referential integrity.
  5. 05
    ExplorationWrote exploratory queries to understand the structure and distribution of the data.
  6. 06
    Business questionsAnswered the defined questions with joins, aggregations, filtering and subqueries.
  7. 07
    OptimisationRefined joins and removed unnecessary calculations for better performance.
  8. 08
    Insight extractionInterpreted results to explain trends and behaviours, not just numbers.
  9. 09
    DocumentationOrganised the SQL scripts, summarised results and described the process.

Key insights

  • Identified sailors who chartered specific boats — and those who never did — highlighting different usage behaviours.
  • Analysed activity by boat characteristics such as colour, revealing preferences for certain boat types.
  • Used pattern matching to find sailors by name characteristics, demonstrating advanced SQL filtering.
  • Combined multiple tables into a complete charter history: sailor names, boat IDs and charter dates.

The outcome

A project that clearly demonstrates analytical thinking and SQL proficiency.
